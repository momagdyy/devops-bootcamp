# Build Tools Labs

## Lab 1: Gradle
### Steps:
- Installed Gradle
- Cloned source code from GitHub
- Ran Unit Tests using: gradle test
- Built App using: gradle build
- Generated artifact: build/libs/ivolve-app.jar
- Ran App using: java -jar build/libs/ivolve-app.jar
- Output: Hello Ivolve Trainee

## Lab 2: Maven
### Steps:
- Installed Maven
- Cloned source code from GitHub
- Ran Unit Tests using: mvn test
- Built App using: mvn package
- Generated artifact: target/hello-ivolve-1.0-SNAPSHOT.jar
- Ran App using: java -jar target/hello-ivolve-1.0-SNAPSHOT.jar
- Output: Hello Ivolve Trainee
